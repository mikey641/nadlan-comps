# Security policy

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/mikey641/nadlan-comps/security/advisories/new)
rather than a public issue. You can expect an acknowledgement within a few days.

In scope: the package code, the CLI, and the Cloudflare relay in `relay/` (for example, a way to use
a deployed relay as an open proxy).
